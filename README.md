# Arden Exteriors Website

This is a static, responsive website package. It contains the full source and the local hero video.

## Files

- `index.html` — page structure and editable content
- `styles.css` — responsive design and color system
- `script.js` — scroll navigation, GSAP motion, FAQ and testimonials
- `assets/hero-roof.webm` — hero background video
- `DESIGN.md` — visual system and editing guide

## Use

Open `index.html` in a browser or run a static server from this folder. To update the hero video, replace `assets/hero-roof.webm` while keeping the same filename, or update the video source in `index.html`.
